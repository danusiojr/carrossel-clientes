# Embeds do portfolio — danusiojunior.com

Paginas HTML servidas pelo GitHub Pages e incorporadas no site do Wix
(elemento "Incorporar site").

| Caminho | Conteudo |
|---|---|
| `/` | carrossel de logos de clientes |
| `/vila-torem/` | hero com 4 videos verticais lado a lado |
| `/fesc/` | hero de video unico |
| `/programa-office/` | hero de video unico |
| `/granos/` | hero de video unico |
| `/casa-do-para/` | hero de video unico |
| `/oab-ceara/` | hero de video unico |

Os videos vem do Media Manager do Wix (video.wixstatic.com). Cada hero
repete apenas uma janela do filme: evita baixar dezenas de MB e pula os
trechos com legenda queimada.

Editar e dar push atualiza o site sozinho, sem passar pelo editor do Wix.
